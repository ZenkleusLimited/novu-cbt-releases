NOVU CBT
Install Requirements Help

Computer-based exams on your school's own network

Install Novu CBT on one computer. Students sit their exams from any laptop, tablet or desktop on the same Wi-Fi or cable network, with no internet needed during the exam.

Download for Windows Release notes and earlier versions

For Windows 10 and 11 (64-bit).

Install in three steps

Do this once, on the computer that will hold your exams.

  1. Download and run the installer

    Open Novu-CBT-Setup.exe and follow the prompts. If Windows shows a warning, see what to click.

  2. Open Novu CBT on the exam computer

    Choose the computer that will hold the exams. Keep it switched on and on the school network while exams run.

  3. Connect student devices

    Novu shows its address on the Overview screen. Students type that address into a browser on the same network and sign in to their exam.

If Windows shows a warning

Novu CBT is new software, so Windows may stop the installer with a blue box that says Windows protected your PC. This is expected.

Click More info, then click Run anyway. Installation then continues as normal.

If your browser says the file isn't commonly downloaded, choose Keep. Only download Novu CBT from this page.

What you need

One computer runs Novu. Every other device only needs a web browser.

Exam computer

  • Windows 10 or 11, 64-bit
  • 4 GB of memory or more
  • 2 GB of free disk space
  • Stays on for the whole exam

Student devices

  • Any laptop, desktop or tablet
  • A current browser: Chrome, Edge, Firefox or Safari
  • Nothing to install

Network

  • A Wi-Fi router or network switch linking all devices
  • Internet only to download Novu and get updates

Help

Answers to the questions schools ask most.

Novu opens to a blank window

The computer is missing Microsoft WebView2, which Novu needs to display its screens. Install the WebView2 Runtime. For a computer without internet, download the standalone installer on another computer and copy it across.

Updating Novu

When the exam computer is online, Novu checks for new versions and asks staff before installing. It never updates during an exam, and it backs up your data first.

Moving to a new computer

Install Novu on the new computer, then restore your latest backup file (.nbk) using your recovery phrase. Your exams and results come with it.

Checking your download

Each release lists a checksum in SHA256SUMS.txt. In PowerShell, run Get-FileHash .\Novu-CBT-Setup.exe and compare the result.
